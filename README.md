# GitHub Chronology — PoUW Observatory

A local-first, evidence-driven observatory of useful work across seven scales, from artifact to identity. It combines historical reconstruction and continuous event ingestion with transparent measurements, goal-relative gap analysis and reversible projections.

**North star:** maximize users' factual visibility into what they produce, its effects and evolution; reveal blind spots and gaps against explicit objectives, so effort can be directed toward useful improvement.

Start with [product](docs/specs/S00-product.md), [domain](docs/specs/S01-domain.md), [evidence](docs/specs/S02-evidence.md) and [first use case](docs/use-cases/UC-001-observe-pr.md). [Delivery method](docs/METHOD.md) and [architecture candidate](docs/adr/0001-architecture.md).

Status: proposed G0 foundations; no deployed observatory or verified complete acquisition. PR #1 is an acquisition experiment, not the product architecture. Issue #2 investigates acquisition strategies; archive availability does not block the first vertical slice.

Code and generic specifications may be public. Corpus, personal goals, private source material and third-party data stay private by default. GitHub and other providers remain source authorities. No judgment grants execution authority or rates intrinsic human worth.
